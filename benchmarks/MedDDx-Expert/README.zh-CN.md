# MedDDx-Expert：EDR 向 MedLA 的跨架构迁移

[English](README.md) | 中文

本目录保存 Gemma 3 12B IT 在完整 483 题上的配对实验，比较**采用共享 MedCorp 证据接口的 MedLA**与**相同框架加 EDR**。实验于 2026 年 10 月 2 日完成，使用官方发布的 Expert/hard 全量题集，没有筛选题目。

## 主结果

| 条件 | 正确 / 总题数 | 正确率 |
| --- | ---: | ---: |
| MedLA + 共享证据 | 135 / 483 | 27.95% |
| MedLA + 共享证据 + EDR | 150 / 483 | 31.06% |
| EDR 提升 | +15 | **+3.11 个百分点** |

EDR相对基线的正确率增长为**11.11%**，纠正30道基线错题，另有15题由对变错。

全量正确率增量的配对 bootstrap 95% 置信区间为 **[+0.41，+5.80] 个百分点**，双侧精确 McNemar 检验 **p = 0.0357**。统计单位是配对题目，bootstrap 重采样 20,000 次；统计重采样种子与生成种子分开记录在 `results/analysis_483.json` 中。

第63、261、307、314题为共同首轮技术失败，两组均无最终选项并计错。主结果覆盖完整**483题**，其中**479题**具有完整配对推理。

## 首轮分歧题目的最终准确率

479道题具有有效且共享的首轮回答，其中468道至少出现两个不同选项，11道全体一致。两组在同一首轮分歧集合上比较最终结果。

| 统计组 | 题数 | 基线正确 | EDR正确 | 准确率增益 |
| --- | ---: | ---: | ---: | ---: |
| 完整题集 | 483 | 135 | 150 | +3.11 pp |
| 首轮存在分歧 | 468 | 125 | 140 | **+3.21 pp** |
| 首轮全体一致 | 11 | 10 | 10 | 0.00 pp |

在首轮分歧题目上，准确率由26.71%升至29.91%。EDR纠正343个基线错误中的30个（8.75%），另有15题由对变错。

题目编号与配对统计见[首轮分歧统计](../../analysis/initial_disagreement_metrics.json)。在源码包根目录运行 `python -B tools/summarize_initial_disagreement.py` 可复算。

EDR生成804份屏蔽历史的回答，并执行2,346次三视角概率探测。逐次调用计数见 [results/execution_audit.json](results/execution_audit.json)。

## 机制证据

| 轨迹指标 | 基线 | EDR |
| --- | ---: | ---: |
| 讨论轮次总数 | 590 | 782 |
| 每题平均讨论轮次 | 1.22 | 1.62 |
| 每题首轮 + 讨论阶段 | 2.22 | 2.62 |
| 首轮分歧题中的提前错误一致 | 326 | **263** |
| 进入终局裁决的题目 | 9 | 48 |
| 每题检索阶段 | 1.00 | 1.00 |

提前错误一致指468道共同首轮分歧题中，在第三讨论轮之前以一致错误答案终止，减少**63题（19.33%）**。这一变化与讨论深度增加支持EDR的持续纠错机制。两组同样只检索一次并共享六篇文档，深度差异发生在原有轮次上限内。首轮加讨论阶段不含探针和终局裁判，均值以全部483题为分母，技术失败计入已尝试的首轮阶段。

基线错题中，有 **297** 题的首轮 17 份回答已经包含正确选项，EDR 修复其中 **29** 题，修复率 **9.76%**。另一道修复题为第 **21** 题，其全部首轮回答均未出现正确选项，正确选项在后续推理中被发现。两类现象分别展示了对已有正确候选的恢复，以及后续轮次发现正确答案的能力。

| 题目 ID | 标准答案 | 基线轨迹 | EDR 轨迹 |
| --- | --- | --- | --- |
| 2 | C | 讨论三轮，终局裁决选择 B | 第二轮分配一名独立代表，形成 C/C 共识 |
| 21 | D | 首轮仅有 A/B/C，第一轮讨论形成 A/A/A | 第一轮两名独立代表提出 D，第二轮形成 D/D |
| 85 | D | C/A/C/A，随后 A/A | D/A/C/A，随后 D/D/A，最终 D/D；三轮均使用独立分支 |

ID 沿用上游从 0 开始的题目索引。完整生成论证保存在共享首轮文件和两组条件轨迹中。

## Token消耗

依据模型服务的用量回执，统计Gemma在这套完整483题MedLA配对评估中的输入、输出和总token。计数包含首轮医学推理、逻辑检查、代表回答、概率探针与终局裁决；共享或复用回答在两种条件中分别计入，所有已记录token用量的调用均纳入统计。

| 条件 | 输入（百万） | 输出（百万） | 总量（百万） |
| --- | ---: | ---: | ---: |
| MedLA | 140.114 | 18.387 | 158.501 |
| MedLA + EDR | 163.372 | 18.274 | 181.646 |

EDR使准确率提高**3.11个百分点**，总token增加**14.60%**，输出token减少**0.61%**。独立代表的历史屏蔽减少上下文输入，抵消了三视角概率探针的部分输入开销。

[汇总、分阶段和逐题token统计](results/token_usage_483.json)单独保存，不改变已有推理轨迹。表格数值保留三位小数。

## 运行环境

| 项目 | 配置 |
| --- | --- |
| 解题与概率探测模型 | Gemma 3 12B IT，服务名 `gemma-3-12b-it` |
| 精度 | BF16，未量化 |
| 生成参数 | 温度 0.7，最大输出 8,000 tokens |
| 首轮 | 17 名智能体，每名顺序排除三个选项，执行原生首轮逻辑检查 |
| 讨论 | 最多三轮，每个不同答案由原生机制选出一名代表 |
| 逻辑示例 | 原生 100 条示例库中的 one-shot 示例 |
| 检索 | MedCorp，BM25 召回 32 篇，MedCPT 重排保留六篇 |
| 输入证据 | 每篇标题和最多 1,200 个正文字符 |

上表为实验本身的模型、生成与检索设置；服务部署细节不属于本次发布内容。

## 框架与接入位置

固定版本 MedLA 的选项排除、逻辑检查、代表选择、反驳与终局裁决函数直接从上游 Python 源码复用。两组所有原生模型角色接收同一份题目证据；检索只使用原题，在首轮之前进行一次，返回文档的顺序和内容在该题内共同沿用。首轮材料只生成一次；后续相同请求继续复用基线输出，直到 EDR 首次实际屏蔽历史。

每轮代表讨论之前，EDR 对原始 A-D 选项进行证据视角 E、历史视角 H、联合视角 EH 概率探测，沿用原本的最高概率选项变化门控与总变差评分：

```text
TV_E = 0.5 * sum_a |p_EH(a) - p_E(a)|
TV_H = 0.5 * sum_a |p_EH(a) - p_H(a)|
s = max(0, TV_E - TV_H)
m8 = 0（E 与 EH 最高概率选项相同或最高概率并列时）；
     否则 min(6, floor(6*s + 0.5))
m = min(N - 1, floor(N*m8/8 + 0.5))
```

N 为实际选出的代表人数，通常为二至四人。按原生顺序取前 m 名代表进入独立分支，输入原题、原始选项、当前候选标签与证据，不输入自身上一轮答案和论证，也不输入同伴论证及逻辑报告；其余代表保留原生讨论上下文。当前候选标签是提示词输入，原生答案解析仍接受原始合法 A-D 选项。代表淘汰、全体一致终止和终局裁决继续由 MedLA 控制，首轮逻辑报告沿用原报告，没有额外逐轮重做。

HTTP 接口和输出格式适配在两组完全相同。公开接入器复用 `src/edr.py`，完整上游框架另行下载，参见[接入说明](../../docs/INTEGRATION.md)。

## 文件内容

| 文件 | 内容 |
| --- | --- |
| `results/final_scores_483.json` | 汇总成绩与全部 483 题的最终选项、正确性 |

三个 JSONL 均为 483 条。两组条件文件按 ID 引用共享首轮，避免重复存储 17 份首轮长论证；存在终局裁决或讨论格式修正输出时保留相应完整文本。原题文件和模型权重仍从上游获取。

## 客观历史屏蔽对照

完整 [MAD-M²模块迁移对照](madmm_objective/README.zh-CN.md)中，客观历史屏蔽为 **145/483（30.02%）**，MedLA 基线为 **135/483（27.95%）**，MedLA + EDR 为 **150/483（31.06%）**。三组共用相同首轮材料与检索证据。EDR 比 MAD-M²高 **1.04 个百分点**；MAD-M²自身比基线高 **2.07 个百分点**。在468道首轮分歧题目上，客观版答对135题（28.85%），EDR答对140题（29.91%），相差1.07个百分点。483 条生成轨迹、筛选分数与历史掩码位于子目录中，原有基线/EDR结果与轨迹保持不变。
