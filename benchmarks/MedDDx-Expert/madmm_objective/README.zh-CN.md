# MedLA + MAD-M² 客观历史屏蔽

[English](README.md) | 中文

本目录保存 Gemma 3 12B IT 在 MedDDx-Expert 全483题上的**模块移植对照**。
移植 *Multi-Agent Debate with Memory Masking* 的官方客观评分与筛选机制，
接入 MedLA 的代表讨论轮。宿主为既有实验中带共享 MedCorp 证据接口的 MedLA。

## 全量结果

| 条件 | 正确数 / 总题数 | 正确率 | 相对基线 |
| --- | ---: | ---: | ---: |
| MedLA + 共享证据 | 135 / 483 | 27.95% | - |
| MedLA + 共享证据 + MAD-M²(O) | 145 / 483 | 30.02% | +2.07 pp |
| MedLA + 共享证据 + EDR | 150 / 483 | 31.06% | +3.11 pp |

EDR比客观屏蔽多答对5题，观察到的差值为 **+1.04 个百分点**。
MAD自身对基线也有正提升：修复26题、误伤16题，净增10题。
MAD对EDR的配对变化为修复33题、误伤38题，净少5题。完整题号均保留。

479题完成，63、261、307、314四题继承共享首轮技术失败，各条件统一计错，
没有为MAD重新生成这些题的首轮。MAD没有新增技术失败。

## 移植机制

评分与筛选遵循原作者发布代码：

```text
score = exp(mean(finite rank-1 token log probabilities))
threshold = sorted(scores, reverse=True)[n // 2]
keep_i = score_i > threshold
```

官方变量名为`perplexity`，实际计算是每个生成位置最高概率token的几何置信度，
分数越高越保留。论文文字描述为只保留困惑度最低的一份；默认3智能体时，官方
严格中位数规则通常也保留一份。本实验遵循**官方代码**：无并列时17留8、4留2、3留1、2留1，
不补齐并列项。

MedLA首轮每个智能体有三次有效医学排除回答，按token数对三段对数评分加权合并。
保留同伴时，其原生逻辑报告仍随历史输入，但逻辑报告不计入质量评分。
原医学生成记录没有保存token概率，因此保持已有文本与原上下文不变，teacher-forcing
补算置信度，并加入一个结束轮次token；没有重新生成首轮答案。后续医学回答直接保存
真实`logprobs`，`top_logprobs=1`。

每轮讨论前，屏蔽低分的**自身及同伴历史**，保留当前候选选项和同一证据块。
原生代表选择、排除流程、停止规则及最终裁决不变；最终裁决器不屏蔽。
对应调用使用相同生成种子与温度。

## 环境与文件

Gemma 3 12B IT为BF16，温度0.7，最大输出8000 token。
使用与基线相同的首轮材料和6文档证据。

`results/` 保留三种方法全量成绩、逐题最终选项、修复/误伤题号、执行核验和失败记录；
`traces/` 保留483条完整生成回答、逐轮评分和阈值、掩码、可见历史及裁决。
首轮完整文本引用父目录的`traces/shared_initial_483.jsonl`。

接入见[接入说明](../../../docs/INTEGRATION.md)。
原作：[论文](https://arxiv.org/abs/2603.20215)，ICLR 2026；
