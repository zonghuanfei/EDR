# MedXpertQA：Gemma 3 12B IT 跨模型评估

[English](README.md) | 中文

本目录包含 Gemma 3 12B IT 的首次全量 EDR 评估，将 MedXpertQA 主实验扩展到第二个模型。两组 Gemma 实验均使用 MA-RAG-int、MedCorp 检索、每轮八份求解回答和相同的推理参数。共享首轮回答后，EDR 在仅依据证据的独立推理与结合历史回答的讨论之间，自适应分配这八份回答。

## 完整题集结果

| 条件 | 答对 / 490 | 准确率 | 相对 MA-RAG-int 的差异 |
| --- | ---: | ---: | ---: |
| MA-RAG-int | 74 / 490 | 15.10% | -- |
| MA-RAG-int + EDR | **93 / 490** | **18.98%** | **+19 题；+3.88 个百分点** |

EDR纠正34道基线错题，另有15题由对变错，净增加19道正确答案。

同一批490题上的 [Qwen实验](../qwen3.8%2027b/README.zh-CN.md)中，完整成绩从209/490提高到236/490。两个模型在完整题集和首轮分歧题目上均呈正向提升。

## 首轮分歧题目的最终准确率

489 道题形成了有效的首轮八份选项决策，其中 351 道存在首轮分歧，138 道首轮一致。两组实验在这 489 题上的首轮回答一致。第 438 题在两组条件下均保留八份生成回答，但选项标签无效（`None`），无法形成有效轮次决策；两组的回答池不同。双方均将该题记为技术失败并计错。最终结果分层如下：

| 首轮状态 | 题数 | MA-RAG-int 答对 | EDR 答对 | EDR 差异 |
| --- | ---: | ---: | ---: | ---: |
| 存在分歧 | 351 | 52 | **71** | **+19** |
| 全体一致 | 138 | 22 | 22 | 0 |
| 首轮选项解析无效 | 1 | 0 | 0 | 0 |

在共享有效首轮回答、且至少出现两个不同选项的351道题目上，准确率由52/351（14.81%）升至71/351（20.23%），提高**5.41个百分点**。EDR纠正299个基线错误中的34个（11.37%），另有15题由对变错。

题目编号与配对统计见[首轮分歧统计](../../../analysis/initial_disagreement_metrics.json)。在源码包根目录运行 `python -B tools/summarize_initial_disagreement.py` 可复算。

三次 Gemma 运行汇总见 [multiseed/README.zh-CN.md](multiseed/README.zh-CN.md)，三次完整题集结果均为正向提升。

## 独立推理与持续纠错

当共享讨论开始向错误答案收敛时，EDR 保留其他解释。在 MA-RAG 的全体一致停止规则下，这些备选答案能够使检索与推理继续进行，为修正答案提供后续机会。

在 351 道首轮分歧题中，提前因错误共识而终止的题数从 **294 降至 217**。这里的“提前错误共识”指八份回答选择同一个错误选项，并在第 2–7 轮终止，尚未达到八轮上限。在 155 道题上，当基线已经因错误共识终止时，EDR 在对应轮次仍未全体一致，并通过后续推理修复了其中 **28 题（18.06%）**。

第 27 题展示了一个具体过程。标准答案为 J，两组实验从相同的八份首轮回答出发：

| 阶段 | MA-RAG-int | EDR 独立分支 | EDR 讨论分支 | EDR 进展 |
| --- | --- | --- | --- | --- |
| 第 1 轮 | `D D D D D D B H` | 共享首轮回答池 | 共享首轮回答池 | 首轮存在分歧 |
| 第 2 轮 | `D D D D D D D D`；以 D 终止 | `H D J J J D` | `D D` | D 仍占多数，但分歧使流程继续 |
| 第 3 轮 | 已终止 | `J J J J J J` | `J J` | 全体一致选择正确答案 J |

讨论分支仍一致选择 D 时，独立分支产生了 J。正确备选答案的保留使系统进入下一轮检索与讨论，随后八份回答全部选择 J。这条轨迹展示了保留独立判断如何使原本以错误共识终止的推理过程获得纠错机会。

## 推理轮次与检索次数

统计覆盖全部 490 题，包括技术失败。一个推理轮次指一次生成八份回答的阶段；保留但未形成有效最终决策的阶段也计一次。一个检索轮次指轨迹中保留的一次查询生成与检索阶段。下表为总数，括号内为每题均值。

| 条件 | 推理轮次：总数（均值） | 检索轮次：总数（均值） | 检索查询数：总数（均值） |
| --- | ---: | ---: | ---: |
| MA-RAG-int | 1,159 (2.37) | 669 (1.37) | 2,676 (5.46) |
| MA-RAG-int + EDR | 1,629 (3.32) | 1,139 (2.32) | 4,556 (9.30) |

总数包含 MA-RAG-int 的四个不完整推理轮次及 EDR 的六个不完整推理轮次。每个保留的检索阶段均有四条查询。共享前缀在每个条件下各计一次，技术重试不额外计为逻辑阶段。EDR 的 E/H/EH 探针属于独立推理调用，不计入上表。可在数据包根目录运行 `python tools/summarize_rounds_retrieval.py` 重新计算。
