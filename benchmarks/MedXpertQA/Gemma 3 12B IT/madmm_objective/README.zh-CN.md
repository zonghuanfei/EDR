# MedXpertQA：MA-RAG-int＋MAD-M² 客观历史屏蔽

[English](README.md) | 中文

本目录保存 Gemma 3 12B IT 在完整 490 题上的近邻模块对照实验。
将《Multi-Agent Debate with Memory Masking》的客观筛选机制接入 MA-RAG-int，
保留原本的解题、检索、聚合与终止规则，只过滤下一轮解题智能体看到的上一轮回答。
原作：[MAD-MM](https://github.com/tmlr-group/MAD-MM)，固定提交
`f02069add08280b764d059a2f06ca0043aa093e2`；
[论文](https://arxiv.org/abs/2603.20215)。题库来源见 [../DATASET.md](../DATASET.md)。

## 运行机制

每份上一轮回答，从每个生成位置取概率最高 token 的对数概率，再计算：

```text
分数 = exp(全部有效生成位置的最高 token 对数概率的平均值)
阈值 = 八个分数降序排列后，下标为4的分数
保留 = 分数严格大于阈值
```

这与原作代码一致。原代码把分数命名为 `perplexity`，实际表达式是最高 token
概率的几何平均数，并非通常带负号定义的困惑度，也不使用标准答案。
严格阈值遇到同分不会补位。

本次每次均留下四份历史回答、屏蔽四份。**八名智能体仍全部生成新回答，
共同参考筛选后的四份历史**，并保留原架构的相对展示顺序。
这不是 EDR 的“部分独立＋部分讨论”分配。当前检索证据完整保留；
生成查询词的智能体仍看到完整八份上一轮回答。每一轮重新计算新分数并筛选。

首轮八份回答及第一次查询、检索材料沿用基线，并控制顺序一致。
有首轮分歧的题从第二轮开始执行屏蔽，此后的解题与检索由客观版继续生成。

## 失败记录与配置

486题完成；26、179、429三题因最终选项解析失败而终止；438题继承共同首轮的生成失败。
四题均计错，失败轮次回答保留；438题引用共享首轮失败记录。

主要配置：Gemma 3 12B IT、BF16、每轮八份回答、最多八轮；
解题温度0.7、查询温度0；解题及查询输出上限8192 token。
检索沿用 MedCorp、BM25召回与MedCPT重排，
每阶段最多四条查询、每条召回32篇并保留两篇。

## 文件与源码

- `traces/ma_rag_int_plus_madmm_objective_490.jsonl`：每题一行，保存各轮完整八份回答、
  最终选项、失败状态、查询词与文献ID／标题／分数。
- 每轮 `history_mask`：保存八个分数、阈值、布尔掩码、保留／屏蔽编号、展示顺序。
  回答编号从0开始。
- `results/final_scores_490.json`：全量成绩、逐题结果与修复／误伤。
- `results/execution_audit.json`：评分与请求核验结果。

基线与EDR轨迹见父目录的 `traces/`。逐轮评分决定每次历史筛选。
重复命中文献的导出分数采用查询编号中的首次出现值；父目录与本对照的取分顺序不同。
共同文献正文和顺序保持一致，相关性分数作为元数据保存，不进入求解输入。

源码为根目录 `src/madmm_objective.py`，实现上述客观分数与严格中位筛选，与实验运行器无关；
完整原始MA-RAG与检索库仍单独获取。
历史筛选方法来自MAD-MM，源码提供其MA-RAG适配器。
许可证及第三方归属沿用根目录 `LICENSE.md`、`NOTICE.md`。
