# 首轮之后的正确候选发现

[English](CANDIDATE_DISCOVERY.md) | 中文

本分析考察首轮回答池未出现正确选项之后，EDR 是否在后续推理中发现正确候选，
补充候选保留与最终准确率分析。

## 指标定义

主要统计集合要求：基线与 EDR 共享八个有效首轮选项，首轮存在分歧，且其中没有
正确选项。后续任一轮、任一回答出现标准答案选项，即记为发现。每题只计一次，
重复出现或消失不会重复计数。发现正确候选与最终选对答案分别统计。

发现率的分母由共享首轮状态确定。首轮解析无效或未匹配的题目仅排除此项诊断，
仍保留在原全量评分中。首轮分歧题目的准确率定义见[统计报告说明](STATISTICAL_REPORTING.zh-CN.md)。

| 实验 | 主要统计集合题数 | 基线后续发现 | EDR 后续发现 |
| --- | ---: | ---: | ---: |
| MedXpertQA / Qwen | 100 | 5（5.00%） | 16（16.00%） |
| MedXpertQA / Gemma 初始运行 | 214 | 10（4.67%） | 45（21.03%） |
| MedXpertQA / Gemma 2026091900 | 202 | 9（4.46%） | 43（21.29%） |
| MedXpertQA / Gemma 2026091909 | 218 | 12（5.50%） | 49（22.48%） |

Gemma 三次运行中，分别有 34、30、41 题的正确选项首次仅出现在独立分支。
文件分别保留首次发现发生在仅讨论分支、两个分支及未记录分支标签轮次的情况。

Qwen MedXpertQA同一百题中，门控随机分配在17题发现正确选项，EDR在16题发现；其中最终
答对分别为7题和12题。完整题集答对数分别为216与236。候选发现与最终选择分别描述协作修正
的不同环节。

## 数据与复算

四个MedXpertQA实验目录均包含 `results/candidate_discovery.json`，其中记录集合大小、发现率、
逐题编号、首次发现轮次与分支、累计发现曲线、终轮正确候选是否存在及最终正确性。
Qwen文件另外包含分配种子42的门控随机策略。以下命令只读取已有轨迹，不调用模型：

```bash
python tools/analyze_candidate_discovery.py --experiment medxpertqa_qwen
```
